# Домашнє завдання № 6 — Kafka та Spark Structured Streaming

Генератор надсилає вимірювання до `building_sensors`. Spark обчислює середню
температуру та вологість, застосовує умови з `alerts_conditions.csv` і записує
сповіщення в `building_sensors_alerts`. Окремий споживач читає результати з Kafka.

## Підготовка

Потрібні Python із модулем `venv`, Java для запуску Spark та доступ до Kafka.
Під час першого запуску також потрібен інтернет для встановлення Python-залежностей
і завантаження Spark Kafka-конектора.

У всіх терміналах перейди до папки проєкту. Від кореня репозиторію курсу:

```bash
cd hw6/goit-de-hw-06
```

Якщо `.env` ще немає, створи його з прикладу:

```bash
cp .env.example .env
```

У `.env` вкажи адресу брокера та свої облікові дані:

```dotenv
KAFKA_BOOTSTRAP_SERVERS=77.81.230.104:9092
KAFKA_USERNAME=your_username
KAFKA_PASSWORD=your_password
KAFKA_SECURITY_PROTOCOL=SASL_PLAINTEXT
KAFKA_SASL_MECHANISM=PLAIN
```

Kafka має містити топіки `building_sensors` і `building_sensors_alerts`.
Скрипти цього проєкту не створюють їх явно; якщо автоматичне створення на брокері
вимкнене, топіки потрібно створити заздалегідь.

Підготуй середовище один раз перед паралельним запуском:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
java -version
```

`run.sh` також уміє створювати `.venv` і встановлювати залежності автоматично.
Активувати середовище вручну в кожному терміналі не потрібно.

## Запуск у трьох терміналах

У кожному терміналі робочою папкою має бути `hw6/goit-de-hw-06`.
Усі три процеси залишаються працювати одночасно.

### Термінал 1 — обробка Spark

```bash
bash run.sh average_sensors
```

Дочекайся запуску потокового запиту. Під час першого запуску Spark завантажує
Kafka-конектор, тому старт може тривати довше.

Spark використовує хвилинне вікно зі зсувом 30 секунд та watermark 10 секунд.
Для нового запиту без checkpoint читання починається з нових повідомлень
(`startingOffsets=latest`). При повторному запуску позиція читання
відновлюється з `checkpoint/sensor_alerts_kafka`.

### Термінал 2 — генерація вимірювань

```bash
bash run.sh produce_sensors
```

Кожні дві секунди генератор надсилає запис із полями `id`, `temperature`,
`humidity`, `timestamp` до `building_sensors`. Запис друкується після
підтвердження надсилання Kafka.

У поточній реалізації температура генерується в межах 45–55, вологість — 15–85.
Такий діапазон температури дозволяє продемонструвати сповіщення
`104 — It's too hot` після завершення вікна.

### Термінал 3 — читання сповіщень

```bash
bash run.sh consume_alerts
```

Споживач виводить назву топіка, partition, offset і JSON повідомлення з полями
`window`, `t_avg`, `h_avg`, `code`, `message`, `timestamp`.

При кожному запуску він читає всі доступні збережені повідомлення з початку
топіка (`earliest`), а потім очікує нові. Для перевірки поточного запуску
дивись на час у `window` і `timestamp`.

Перші нові сповіщення зазвичай з'являються через 1–2 хвилини після початку
генерації, але запуск Spark може додати затримку. Залиш генератор працювати:
нові події потрібні для просування watermark і завершення часових вікон.

## Перевірка результату та скриншот

У третьому терміналі має з'явитися рядок на зразок:

```text
TOPIC=building_sensors_alerts PARTITION=0 OFFSET=0
```

Номер partition та offset можуть відрізнятися. Під цим рядком буде JSON
сповіщення. Наприклад, `code="104"`, `message="It's too hot"` і `t_avg >= 40`
відповідають температурній умові з `alerts_conditions.csv`.

Для скриншота покажи назву вихідного топіка та JSON із середніми значеннями,
кодом, повідомленням і часовим вікном. Можна розташувати всі три термінали поруч,
щоб одночасно показати генерацію, роботу Spark і читання результатів.

## Зупинка

Натисни `Ctrl+C` у кожному терміналі. Папка `checkpoint` зберігає стан Spark
для наступного запуску.

## Якщо результатів немає

- Перевір адресу брокера, логін і пароль у `.env`, доступність Kafka та наявність обох топіків.
- Перевір, чи Spark запустився без помилок Java або завантаження Kafka-конектора.
- Залиш генератор працювати кілька хвилин і перевір вивід Spark.
- Врахуй, що результати з'являються лише для вікон, які відповідають хоча б одній умові з `alerts_conditions.csv`.
